# Configuration reference

Configure credentials only in n8n's Credentials UI. This directory intentionally contains no secrets.

Recommended Gmail search query for historical testing:

```text
newer_than:30d (job OR internship OR hackathon OR fellowship OR scholarship OR hiring)
```

Gmail search does not support arbitrary Boolean syntax. Keep queries short and test them in Gmail first. Set the destination spreadsheet and worksheet manually in the Google Sheets node after import.
